# personal-apps

Small single-purpose tools for myself. Static pages on GitHub Pages; data lives in Google Drive.

- `piano/` — «Клавиши», a piano trainer for the tablet: lessons, exercises, songs by notes and by chords. How it's built and how to
  check a change: [`piano/README.md`](piano/README.md). The engine contains no lessons or songs.
- `bridge/piano/Code.gs` — Google Apps Script web app between the page and Drive. Its `/exec` URL is never committed;
  it is pasted once on the device.
